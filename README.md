# SkillsUSA Python Academy 2027

Learn Python by building practical programs and prepare for the SkillsUSA Computer Programming competition. No programming experience is required to start.

This is an independent practice curriculum inspired by the 2021 virtual project themes, not official SkillsUSA material. Confirm the 2027 rules, scoring, and permitted tools with your advisor and current SkillsUSA materials before competing.

## Learning path

Each module follows the same rhythm: **lesson → quiz → coding challenge → project milestone**. After the three projects, try the timed mock exam and polish one project for your portfolio.

| Module | What you'll learn | What you'll build |
| --- | --- | --- |
| 1. [Getting started](modules/01-python-basics/README.md) | Install and run Python; use output and comments | A welcome program |
| 2. Variables and input | Store values, read input, and convert types | A favorite-food questionnaire |
| 3. Math and formatting | Use arithmetic and format numeric results | An order total calculator |
| 4. Calorie Calculator | Combine input, arithmetic, and formatted output | A meal summary with activity estimates based on rates supplied in the exercise |
| 5. Decisions | Use conditions and test grade boundaries | A score-to-letter-grade converter |
| 6. Loops and lists | Collect repeated input and summarize scores | A highest, lowest, and average score report |
| 7. Student Grade Calculator | Write reusable functions and handle invalid or missing scores | A report for a named student and course |
| 8. Dictionaries and menus | Look up prices and keep track of a cart | An interactive concession menu |
| 9. Movie Theater Concessions | Organize checkout, track sales, and write reports to a file | A checkout system with receipts and an optional daily sales report |
| 10. Mock SkillsUSA Exam | Read requirements, manage time, and test edge cases | Three original practice challenges |

## Mock exam preview

- **Restaurant Order System:** Use quantities and prices to calculate and format an order total.
- **Employee Payroll System:** Use functions and conditions to calculate regular and overtime pay from supplied rules.
- **Library Checkout System:** Use loops and dictionaries to track which books are available, checked out, or returned.

For each problem, write down the expected inputs and outputs first. Then test a normal case, a boundary case, and an invalid input. When time is up, score your work against the original requirements and note what to improve before the next attempt.

## Start here

Install [Python 3](https://www.python.org/downloads/), confirm you can launch it, and try printing `Welcome to SkillsUSA Programming`. The [Python Beginner's Guide](https://wiki.python.org/moin/BeginnersGuide) and [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/) are good companions.
